# Desarrollo Web Cliente

Estructura organizada del proyecto:

- `unidad1/` — ejercicios de la unidad 1.
- `unidad2/` — ejercicios de la unidad 2.
- `unidad3/` — repaso y ampliaciones de la unidad 3.
  - `repaso/` — ejercicios de repaso.
  - `ampliacion/ejercicio1/` — ampliación 1.
  - `ampliacion/ejercicio2/` — ampliación 2.
- `materiales/` — PDFs y recursos complementarios.

Esta organización mantiene los ejercicios agrupados por unidad y por tipo de actividad para que sea más fácil navegar por la carpeta.
