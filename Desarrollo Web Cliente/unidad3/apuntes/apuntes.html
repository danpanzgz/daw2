3.10.2. Estructuras de repetición

Volver

Estas estructuras de control se llaman bucles y se emplean para que, de manera repetitiva, se pueda ejecutar «n» veces una instrucción. Es igual que en el resto de lenguajes de programación.

a) For

Se ejecuta un bloque de código mientras la condición indicada sea verdadera.

for (let a = 0; a < 10; a++) {
  console.log(a);
  if (a === 7) {
    break;
  }
}

b) While y Do-While

El bucle while ejecuta el código mientras la condición siga siendo cierta. El do...while se asegura de ejecutarlo al menos una vez y luego comprueba la condición. 

let a = 0;
while (a < 5) {
  console.log(a);
  a++;
}

do {
  console.log('Estoy dentro del do...while');
} while (a !== 5);

c) For in

Se recorre el índice de un array o las propiedades de un objeto. Es útil para recorrer estructuras con clave-valor, sobre todo en objetos. 

const alumno = ['Alberto', 'Lopez', 25];
for (const i in alumno) {
  console.log(alumno[i]);
}

const persona = { nombre: 'Ana', edad: 25, pais: 'Chile' };
for (const clave in persona) {
  console.log(clave, ':', persona[clave]);
}

d) ForEach

Es un método para arrays que ejecuta una función por cada elemento del array. No permite salir con break ni return, así que si necesitas interrumpir el recorrido conviene usar for...of. 

const numeros = [10, 20, 30];
numeros.forEach((valor, indice) => {
  console.log(`Índice ${indice}: ${valor}`);
});

e) For of

Recorre directamente los elementos de un array, string, mapa o conjunto. Es más claro que for...in cuando se quiere iterar sobre valores. 

const alumno = ['Juan', 'Perez', 25];
for (const valor of alumno) {
  console.log(valor);
}

function buscarValor(arr, objetivo) {
  for (const valor of arr) {
    if (valor === objetivo) {
      return `Encontrado: ${valor}`;
    }
  }
  return 'No encontrado';
}
