Diseño de interfaces web

Trabajo con CSS externo

Este ejercicio muestra cómo un archivo CSS independiente puede dar estilo a una página completa de forma ordenada y reutilizable.

La combinación de márgenes, color, tipografía y espaciado mejora la legibilidad y hace que la interfaz sea más atractiva para los usuarios.

Características aplicadas

Se ha usado un fondo claro, una fuente legible de Google Fonts, colores diferenciados para títulos y textos, y una estructura con padding y márgenes adecuados.
