Practica 1 - Procesamiento de datos y modelo simple de IA

Instrucciones rápidas:
- Coloca `california_housing.csv` (Kaggle) en la carpeta del proyecto o en `recursos/`.
- Crear un entorno e instalar dependencias:

```bash
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

- Ejecutar el análisis:

```bash
python p1_analysis.py
```

Entregables generados por el script:
- `p1_memoria.txt` : breve memoria del Punto 1
- `requirements.txt` : dependencias
- `recursos/nulls.txt` : conteo de nulos por columna
- `figures/medhouseval_hist.png` : histograma de `MedHouseVal`
- `figures/decision_tree_d3.png` : imagen del árbol de decisión (max_depth=3)

Si quieres que genere el zip final, dime y lo creo.
